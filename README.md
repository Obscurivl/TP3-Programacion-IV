
# Gestión de Transporte

Trabajo práctico Nº 3 - Aplicación para administrar vehículos, conductores y viajes de una empresa de transporte.

## Requisitos
- Node.js 18 o superior
- MySQL 8 o compatible
- npm

## 1. Configurar y ejecutar el backend
Desde una terminal:

```bash
cd backend
npm install
npm run dev
```

El servidor queda disponible en `http://localhost:3000`.

## 2. Ejecutar el frontend
Abrir otra terminal:

```bash
cd frontend
npm install
npm run dev
```

Vite informa la dirección local, normalmente `http://localhost:5173`.
